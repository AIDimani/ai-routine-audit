# Аудит рутины в нейросети

Скил для Claude и промпт для ChatGPT. Он проходит по твоим прошлым чатам и показывает:

- какие задачи ты отдаёшь нейросети снова и снова;
- где модель тебя не понимает и ты переделываешь;
- сколько часов в месяц на это уходит;
- готовые инструкции, которые закрывают самую частую боль — прямо сейчас.

Анализ идёт внутри твоего аккаунта. Твои чаты никуда не отправляются.

## Claude

1. Скачай **[ai-routine-audit.zip](https://github.com/AIDimani/ai-routine-audit/releases/latest/download/ai-routine-audit.zip)**. Распаковывать не нужно.
2. В Claude открой **Settings → Capabilities → Skills** и загрузи этот файл.
3. Включи поиск по прошлым чатам (там же, в настройках памяти), открой новый чат и напиши: **«запускай аудит»**.

Если поиск по истории выключен, скил предложит короткое интервью из 6 вопросов вместо анализа чатов.

## ChatGPT

1. В настройках персонализации включи память и ссылки на историю чатов.
2. Открой **[prompt.md](chatgpt/prompt.md)**, скопируй текст под чертой целиком.
3. Вставь в новый чат и отправь.

## Что дальше

Аудит закрывает одну задачу готовыми инструкциями. Остальные повторяющиеся задачи можно отдать ИИ-агентам, которые сами берут файлы и делают работу. Как их собрать — на вебинаре «ИИ-сотрудники»: [agents.aicreator.ru](https://agents.aicreator.ru/?utm_source=gh_skill&utm_medium=social&utm_campaign=aw_ai_workers&utm_content=readme)
